# 中文转录优化指南

## 问题：中文识别准确度低

如果遇到中文转录结果不准确，出现重复字词或乱码，请按以下方法优化：

## 解决方案

### 1. 使用更大的模型（推荐）

中文识别对模型要求较高，建议使用：

| 模型 | 中文准确度 | 推荐场景 |
|------|-----------|---------|
| tiny | ⭐⭐ | 不推荐中文 |
| base | ⭐⭐⭐ | 简单对话 |
| **small** | ⭐⭐⭐⭐ | **日常使用（推荐）** |
| **medium** | ⭐⭐⭐⭐⭐ | **高质量转录（推荐）** |
| large | ⭐⭐⭐⭐⭐ | 专业级转录 |

**建议：**
- **普通话录音**: 使用 `small` 或 `medium` 模型
- **方言、口音**: 使用 `medium` 或 `large` 模型
- **专业要求**: 使用 `large` 模型

### 2. 优化的配置参数

系统已自动应用以下中文优化参数：

```python
{
    'language': 'zh',                    # 指定中文
    'task': 'transcribe',                # 转录任务
    'initial_prompt': '以下是普通话的句子。',  # 中文提示
    'temperature': 0.0                   # 降低随机性
}
```

### 3. 音频质量建议

为获得最佳转录效果：

✅ **推荐：**
- 清晰的普通话发音
- 安静的录音环境
- 采样率 ≥ 16kHz
- 格式：WAV、MP3、M4A

❌ **避免：**
- 背景噪音过大
- 多人同时说话
- 音量过低或过高
- 音频压缩过度

### 4. 测试对比

**使用 base 模型：**
```
結果：請問,請問,請問... (大量重复)
准确度：❌ 很差
```

**使用 small 模型：**
```
結果：正确识别，偶尔错误
准确度：✅ 良好
```

**使用 medium 模型：**
```
結果：准确识别，标点正确
准确度：✅✅ 很好
```

## 快速修复步骤

1. **在前端选择更大的模型**
   - 打开上传页面
   - 选择 "Small" 或 "Medium" 模型
   - 重新上传音频

2. **等待模型下载（首次使用）**
   - Small: ~466MB
   - Medium: ~1.5GB
   - 下载后会缓存，之后无需重复下载

3. **检查转录结果**
   - 准确度应该明显提升
   - 如仍不理想，尝试使用 Medium 或 Large

## 进阶优化

### 自定义 initial_prompt

对于特定领域的内容，可以修改提示词：

```python
# 技术内容
'initial_prompt': '以下是关于人工智能和机器学习的技术讲座。'

# 医学内容
'initial_prompt': '以下是医学专业术语的讨论。'

# 法律内容
'initial_prompt': '以下是法律条文和案例分析。'
```

### 调整 temperature

```python
temperature=0.0   # 最保守，准确度最高（推荐）
temperature=0.2   # 略有创造性
temperature=0.5   # 更自然，但可能不够准确
```

## 常见问题

**Q: 为什么 base 模型中文效果差？**  
A: base 模型参数较少（~74M），对中文的支持有限。中文字符集大，需要更大的模型。

**Q: 如何快速清理错误的模型缓存？**  
A: 运行 `python backend/clear_cache.py`

**Q: 能否同时支持中英文混合？**  
A: 可以，设置 `language='zh'` 即可识别中英混合，Whisper 会自动处理。

**Q: 方言支持如何？**  
A: Whisper 主要针对标准普通话训练，方言识别准确度会降低。建议使用 large 模型。
