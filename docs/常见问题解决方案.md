# 常见问题解决方案

## Whisper 模型相关

### 问题：模型校验失败 (SHA256 checksum error)

**错误信息：**
```
RuntimeError: Model has been downloaded but the SHA256 checksum does not not match.
```

**原因：**
- 模型文件下载不完整
- 模型文件损坏
- 网络中断导致下载失败

**解决方法：**

1. **使用清理脚本（推荐）：**
   ```bash
   cd backend
   python clear_cache.py
   ```
   选择"删除 large 模型"或"删除所有缓存"

2. **手动删除缓存：**
   - Windows: `C:\Users\你的用户名\.cache\whisper\`
   - Linux/Mac: `~/.cache/whisper/`
   
   删除对应的 `.pt` 文件，重新运行即可自动下载

3. **使用更小的模型：**
   - 推荐使用 `base` 模型（142MB）进行测试
   - `large` 模型很大（2.9GB），下载时间长

### Whisper 模型说明

| 模型 | 大小 | 速度 | 准确度 | 推荐场景 |
|------|------|------|--------|----------|
| tiny | ~39MB | ⭐⭐⭐⭐⭐ | ⭐⭐ | 快速测试 |
| base | ~142MB | ⭐⭐⭐⭐ | ⭐⭐⭐ | 日常使用（推荐） |
| small | ~466MB | ⭐⭐⭐ | ⭐⭐⭐⭐ | 较高质量 |
| medium | ~1.5GB | ⭐⭐ | ⭐⭐⭐⭐⭐ | 高质量 |
| large | ~2.9GB | ⭐ | ⭐⭐⭐⭐⭐ | 最高质量 |

**首次使用提示：**
- 模型文件会自动下载到缓存目录
- 只需下载一次，之后可离线使用
- 建议先用 base 模型测试，满意后再升级

## 其他常见问题

### moviepy 导入错误

如果遇到 `No module named 'moviepy.editor'`，说明 moviepy 版本不兼容。

**解决方法：**
```bash
pip install --upgrade moviepy
```

### 端口占用

如果提示端口被占用：
```bash
# Windows
netstat -ano | findstr :5000
taskkill /PID <PID> /F

# Linux/Mac
lsof -ti:5000 | xargs kill -9
```

### 前端无法连接后端

1. 确认后端已启动（http://localhost:5000）
2. 确认前端配置正确（vite.config.js 中的代理设置）
3. 检查防火墙设置
