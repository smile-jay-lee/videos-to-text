# 前端显示问题调试指南

## 问题描述
后端成功返回转录结果，但前端界面无法显示。

## 已添加的调试代码

### 1. App.jsx
在 `handleUploadSuccess` 函数中添加了调试日志：
- 打印接收到的数据
- 检查 transcription 字段是否存在
- 确认页面切换状态

### 2. UploadPage.jsx
在上传成功后添加了调试日志：
- 打印上传返回的结果
- 确认 onSuccess 回调被调用

### 3. ResultPage.jsx
在组件渲染时添加了调试日志：
- 打印接收到的 result 对象
- 显示转录文本的长度

## 调试步骤

### 步骤1: 重新构建前端
```bash
cd frontend
npm run build
```

### 步骤2: 打开浏览器开发者工具
1. 按 F12 打开开发者工具
2. 切换到 "Console" 标签
3. 清空之前的日志

### 步骤3: 上传文件测试
上传一个音频/视频文件，观察控制台输出。

### 步骤4: 检查控制台日志

应该看到以下日志顺序：
```
1. Upload successful, result: {success: true, ...}
2. Calling onSuccess with result
3. App.jsx handleUploadSuccess called with: {...}
4. Has transcription: true
5. Transcription length: XXXX
6. Current page set to: result
7. ResultPage received result: {...}
8. Transcription length: XXXX
```

## 可能的问题和解决方案

### 问题1: 没有看到日志7和8
**原因**: ResultPage组件没有被渲染
**解决**: 检查 App.jsx 中的条件渲染逻辑

### 问题2: transcription 字段为 undefined 或 null
**原因**: 后端返回的数据结构不正确
**检查**: 
- 后端 `/api/transcribe` 返回的 JSON 结构
- 是否有 `transcription` 字段
- 字段名是否拼写正确

### 问题3: 页面空白但有数据
**原因**: CSS 样式问题或内容太长
**解决**: 
- 检查 `.text-content` 样式是否正确加载
- 尝试缩短测试文件（使用短音频）
- 检查是否有 JavaScript 错误

### 问题4: 页面没有切换
**原因**: `currentPage` 状态没有更新
**检查**: 
- 是否看到 "Current page set to: result" 日志
- React 是否正确更新状态

## 检查后端返回

在终端中检查后端日志，确认返回的数据格式：
```
INFO - 处理完成: XXXX
```

后端应该返回类似这样的JSON：
```json
{
  "success": true,
  "task_id": "...",
  "filename": "访谈.wav",
  "transcription": "转录的文本内容...",
  "model": "small",
  "duration": 123.45,
  "output_files": ["访谈.wav_transcription.txt"]
}
```
