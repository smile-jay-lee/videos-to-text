**音频**：MP3, WAV, AAC, M4A, FLAC, OGG

## 📝 API接口

### 上传文件
```
POST /upload
```

### 开始转写
```
POST /api/transcribe
```

### 查询状态
```
GET /api/task/<task_id>
```

### 获取结果
```
GET /api/result/<task_id>
```

### 下载文件
```
GET /api/download/<task_id>/<file_type>
```

## 🐛 已知问题

1. **同步处理**：当前转写任务是同步的，处理大文件时会阻塞
   - **解决方案**：后续集成Celery异步任务队列

2. **内存使用**：大模型（medium/large）需要较多内存
   - **建议**：使用base或small模型

3. **进度更新**：当前使用轮询方式
   - **改进**：可使用WebSocket实现实时推送
